OMP evolution V3 uses a file-based multi-step pipeline: SessionLearner extracts durable knowledge into .omp/self-evolution/ files, then InjectionFormatter applies a 7-layer priority injection (AGENTS.md → Memory → Conventions → Skills → Profile → Episodic → Past Episodes) with dynamic token budgets per task type. The skill system delegates evolution to the coding agent. Evolution runs at agent_start/agent_end lifecycle hooks.

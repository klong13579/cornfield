omp currently does not have explicit step-level timing. Tool execution events (tool_execution_start/end) lack timestamps. Session entries have ISO timestamps but no duration fields. TUI renderers do not display elapsed time for tool steps. A three-layer implementation plan (events, session persistence, TUI rendering) has been proposed but not implemented.

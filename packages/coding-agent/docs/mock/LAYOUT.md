# 功能布局设计文档（V5）

> 2026-08-17 · 配套 `docs/mock/pages/*.html`
> 定义 OMP 多端前端的功能区划分、尺寸约束、拖拽行为与响应式规则。
> 前端团队按此文档实现可拖拽布局系统；mock 中 `session-workspace.html` 是参考实现。

---

## 1. 功能区总览

```
┌──────────────────────────────────────────────────────────────────────┐
│ 手机预览按钮（fixed, 顶栏右侧上方浮动）                                  │
├────┬──────────────────────────────────────────────┬───┬──────────────┤
│    │  顶栏 Topbar · 48px                           │   │              │
│ 导 ├──────────────────────────────────────────────┤ 拖│   右侧面板    │
│ 航 │                                              │ 拽│   Sidebar    │
│ 栏 │  内容区 Content（页面主体）                    │ 分│   · 状态      │
│ 60 │                                              │ 隔│   · 可视化    │
│ px │                                              │ 条│   · Todo     │
│    │                                              │ 5 │              │
│    │                                              │ px│   240–520px  │
│    ├──────────────────────────────────────────────┤   │   （可拖拽）  │
│    │  Composer（输入区，工作台专属）                 │   │              │
└────┴──────────────────────────────────────────────┴───┴──────────────┘
```

| # | 功能区 | Mock 选择器 | 职责 |
|---|--------|------------|------|
| A | 导航栏 | `#nav` | 一级页面导航（数据驱动 NAV 数组） |
| B | 顶栏 | `#topbar` | 连接状态、项目/分支、页面级操作、面包屑 |
| C | 内容区 | `#content / #transcript / #stage` | 页面主体（消息流 / 卡片网格 / 表单 / 列表） |
| D | Composer | `#composer` | 消息输入 + 功能工具栏（工作台专属） |
| E | 拖拽分隔条 | `#splitter` | 右栏宽度拖拽手柄 |
| F | 右侧面板 | `#sidebar` | 会话状态 / 可视化 / Todo（tab 切换） |
| G | 手机预览面板 | `#phonePanel` | 375×812 设备模拟器（全局浮层） |

## 2. 尺寸约束

| 功能区 | 默认 | 最小 | 最大 | 可拖拽 |
|--------|------|------|------|--------|
| A 导航栏 | 60px 固定 | — | — | 否 |
| B 顶栏 | 48px 固定 | — | — | 否 |
| C 内容区 | 弹性填充 | 320px | ∞ | 间接（由 F 反向决定） |
| D Composer | 内容自适应（textarea min 52px） | — | — | 否 |
| E 分隔条 | 5px 热区 | — | — | （本身即手柄） |
| F 右侧面板 | **300px** | **240px** | **520px** | **是** |
| G 手机预览 | 420px 固定面板，内嵌 375×812 设备框 | — | — | 否 |

内容区内部容器：
- 工作台消息流：max-width 680px 居中
- 表单/设置类页面：max-width 640–720px
- 列表/网格类页面：不限宽，卡片 `minmax(340px, 1fr)`

---

## 3. 拖拽行为

**交互**：
- 手柄 5px 宽热区，hover / dragging 时显示 `--accent-dim` 底色反馈
- `mousedown` 进入拖拽：`body.resizing` 禁用文本选择、全局 `col-resize` 光标
- `mousemove` 实时更新右栏宽度（反向计算：`window.innerWidth - clientX`）
- `mouseup` 结束拖拽并持久化到 `localStorage["omp.side.w"]`
- **双击手柄复位到 300px 默认宽**

**约束**：clamp(240px, 拖拽值, 520px)；低于 240px 时面板内容不换行错乱即可（mock 未做折叠态，生产中 <240px 建议自动收起为图标条）。

**参考实现**：`pages/session-workspace.html` 底部 script 的 splitter 段（约 20 行，零依赖）。

## 4. 右侧面板（F）内部结构

tab 切换三段，共用一块面板区域：

| Tab | 内容 | 数据 |
|-----|------|------|
| 状态 | 会话 phase、Agent（含类型 + 钉钉绑定）、模型、队列、上下文用量条 | `session_snapshot` |
| 可视化 | Token 速率实时柱状图（1.5s 刷新/mock）、活跃工具列表、命令输出预览流 | `progress` 事件流 |
| Todo | 会话 todo checkbox 列表 | `snapshot.todoPhases` |

生产中「可视化」可扩展插槽：diff 预览、文件树、图表、网页预览——同一 tab 容器内切换视图。

---

## 5. Composer（D）内部结构

两行布局（Claude.ai / ChatGPT 通行模式）：

```
┌─────────────────────────────────────────────┐
│  textarea（min-height 52px，自动增高）         │
├─────────────────────────────────────────────┤
│ [Agent选择器▾] [📎] [🎤] │ [模型▾] [思维▾] [⬆] │
└─────────────────────────────────────────────┘
```

| 控件 | 行为 |
|------|------|
| Agent 选择器 | 头像（含钉钉绑定角标）+ 名称 + CODING/WORKER 类型徽标；下拉按工作区分组 |
| 附件 | 上传文件作为 prompt 上下文 |
| 语音 | 跳语音页 / 原位录音（移动端原位） |
| 模型 / thinking | 触发 `set_model` / `set_thinking_level` |
| 发送/停止 | 原位替换（发送 ⬆ ↔ 停止 ■），`prompt` ↔ `abort` |

---

## 6. Agent 类型与工作区

- **类型**：`CODING`（终端图标，填充徽标）面向研发任务；`WORKER`（公文包图标，描边徽标）面向运营/职能任务。类型决定默认可用工具集与推荐模型。
- **工作区**：Agent 的分组容器（研发工作区 / 运营工作区…）。Agent 列表页按工作区分节 + seg 筛选；Composer 的 agent 下拉按工作区分组。
- **钉钉绑定**：绑定钉钉机器人的 agent 在头像右下角显示钉钉 logo 角标（`--dingtalk: #3296fa`），会话状态区显示「已绑定」。

---

## 7. 响应式规则

| 宽度 | 行为 |
|------|------|
| ≥1280px | 完整三列（导航 + 内容 + 右栏 300px 可拖） |
| 960–1280px | 右栏默认收窄至 280px，允许拖至 240px |
| <960px | 右栏隐藏，「详情」入口改为浮层（同 mobile-session 的 overlay 模式） |
| 移动端（≤430px） | 单栏：顶栏 + 快捷条 + 内容 + Composer；右栏功能全部进浮层；Composer 工具栏保留 agent 选择 + 语音 + 发送 |

---

## 8. 全局浮层

- **手机预览**（G）：fixed 右上按钮触发，右侧滑出 420px 面板，iframe 加载 `mobile-session.html`；遮罩 / Esc / ✕ 关闭。所有桌面页共享。
- **下拉菜单**（agent 选择、模型选择）：向上/向下弹出，`hairline-strong` 边 + 深阴影，点击外部关闭。

---

## 9. 持久化

| Key | 内容 |
|-----|------|
| `localStorage["omp.side.w"]` | 右栏宽度（px） |
| （生产扩展）`omp.layout.*` | 各页 tab 选择、面板折叠态、composer 草稿 |

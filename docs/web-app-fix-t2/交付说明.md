## 变更范围（scope 内）

- `packages/web-app/src/pages/todo/TodoView.tsx`
  - 板子归属从硬编码 `view.activeAgentId ?? "default"` 改为 `boardAgentIdOf(view)`（显式 pin 优先，否则与全站焦点解析同源），标题/占位改用 **Agent 名**（`boardAgentNameOf`）。
  - 顶部新增「看板 Agent」选择器：在本页切换要看/写的 Agent 板子，**不切连接焦点**（调用 `store.setTodoBoardAgent`，默认「跟随焦点」）。
  - 行内操作容器补 `pointer-coarse:opacity-100 max-sm:opacity-100`——无 hover 场景（窄屏/粗指针）不再藏在 hover 后；桌面 hover 显隐行为不回退。
  - 空标题点「添加」给出可见说明（输入框下方常驻提示）。「添加」按钮的禁用外观仍由 T1 的 `.cbtn:disabled` 负责，本任务只补文案。
- `packages/web-app/src/pages/todo/agent-todo-logic.ts`
  - 新增纯函数 `boardAgentIdOf` / `boardAgentNameOf`（同一处定义板子归属，标题、占位、写操作 `agentId` 同源）。
- `packages/web-app/src/state/session-store.ts`（仅 agent-todo 区域，未动 T3 的 model 字段）
  - 新增 `#todoBoardAgent`（null = 跟随焦点）、`setTodoBoardAgent(agentId?)`、`#boardAgentTarget()`、`#boardAgentKey()`。
  - `saveAgentTodo` / `deleteAgentTodo` / `#loadAgentTodos` / `#syncAgentTodos` 改为按 `#boardAgentTarget()` 定向（显式 pin 优先，否则跟焦点）。
  - `#setActiveAgent` 在显式 pin 时**不打断**正在看的板子。
  - 新增视图字段 `todoBoardAgentId`。
- `packages/web-app/test/diag-todo-ownership.test.ts`（新增）

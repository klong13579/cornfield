项目经历（倒序）
① VLA 端到端项目｜2025.06–至今｜零跑

基于 QwenVL 构建端到端 VLA：输入 7 路相机视频 + 导航/自车状态，加轨迹预测专家头，输出未来 4s 轨迹。开环 ade=0.4m / fde=1.2m；实现杭州市区复杂道路 MPCI ≥20km。 重点解决不居中、不加速、画龙。

数据 pipeline：Dataset 采用轻量索引 + 重存储分离——mmap 整份 txt 入内存，idx 偏移 O(1) 定位，parquet row-group 读出 clip（关键帧附近历史/未来窗口）；可插拔链式 Processor 框架（7 路视频解码/裁剪/patch 化、云端定位修正、轨迹与导航路径 BEV 坐标转换、提示词生成），支持采集车与用户车数据生产。
模型 pipeline：复用 Qwen2VL 结构与预训练参数 + 专家头；从智驾数据筛关键视频构建 VQA（场景描述/环境感知/车道情况/自车元动作/规划解释）做垂直域 continue pretrain；全模块 Registry 化（model/head/loss/metric/optimizer/scheduler）配置驱动；分布式 + 混合精度 + 梯度检查点 + 换优化器与视频解码器，分场景构建评估体系。
模型优化及实车问题解决
action head：可学习 traj_token 并行解码全部 waypoints 替代自回归；由预测轨迹改为预测加速度，梯形积分从初始速度/加速度还原速度与轨迹，把运动学约束内嵌进模型保证动力学一致性，另加 vel refine 提质量与可控性。
画龙：主因系统延迟过高，降到 10Hz 大幅缓解。手段：token pruning（视频 token 相似度剪枝 / 视频-文本交互自适应剪枝 / 空间时序 downsample+pixelshuffle）+ vision cache（只算当前时刻 vision encoder 输出，历史复用缓存 token 再拼接）。
不居中：消融定位为标定问题 + 数据分布。3dpe（内外参融入 vision token + 学深度增强纵向）+ center loss（人类偏左驾驶习惯致分布不均）。
不加速：数据采集保守 + 实车加速度趋势，空旷隧道等场景预测先减后加。①元动作预测（meta_action_token + pred head）②隐世界模型预测（world_model_token + pred head，未来帧监督，学"场景是什么及后续如何变化"，解监督稀疏 + 先观察再行动）③流匹配 + 强化学习：FILM 轻量网络学噪声→加速度序列速度场，推理 SDE 采样保多样性并保留生成概率；针对空旷直行不加速设计 reward，训练分类器实车验证 reward 正确性避免 reward hack；GRPO 鼓励组内高 reward 轨迹获高生成概率。
② LeapAI 多任务联合训练框架｜2024.08–2025.05｜零跑

# 02: 交付可发现、可诊断的完整模型目录

**What to build:** 用户可以浏览全部已知模型，而不只是当前已经接入且可用的模型。目录明确说明每个模型为什么可用或不可用，并提供真实的搜索、筛选、排序、详情和当前会话临时切换能力，使“未配置”“已停用”“本地离线”和“模型不存在”保持为不同状态。

**Blocked by:** 01: 建立模型控制中心信息架构

**Status:** ready-for-agent

- [ ] 目录展示全部已知模型，并区分可用、未接入、凭据失效、已停用、本地离线和目录过期
- [ ] 用户可按名称、模型 ID 和 Provider 搜索
- [ ] 用户可按 Provider、能力、输入模态、上下文长度和接入状态筛选
- [ ] 用户可按真实价格、上下文长度、名称和发布时间排序；缺失排序数据的模型明确排在末尾
- [ ] 删除以列表位置冒充“最新模型”的启发式逻辑
- [ ] 模型列表展示输入/输出价格、上下文、能力、状态和引用它的角色
- [ ] 模型详情展示完整能力、限制、数据来源、更新时间和 Provider 接入情况
- [ ] 用户可从目录临时切换当前会话模型；该操作不伪装成持久化默认配置
- [ ] 搜索、筛选、排序、空态、错误态和临时切换具有针对性测试

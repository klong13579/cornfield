# 01: 建立模型控制中心信息架构

**What to build:** 将现有“模型市场”升级为模型控制中心。用户进入后可在模型目录、Provider、运行配置三个独立工作区之间导航，并始终看到当前会话模型、当前配置作用域、模型目录状态和待处理异常。现有模型切换、停用和恢复能力在迁移过程中保持可用，断连和操作失败必须显示真实状态，不再永久加载或静默失败。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `/models` 提供模型控制中心入口，并可进入模型目录、Provider、运行配置三个独立工作区
- [ ] 三个工作区支持独立导航、刷新和返回，不因切换丢失关键上下文
- [ ] 顶部状态区展示当前会话模型、配置作用域、目录新鲜度和异常数量
- [ ] 当前模型切换、模型停用和恢复能力保持可用
- [ ] 未连接状态有明确提示和恢复入口，不再永久显示骨架屏
- [ ] 所有读取和写入失败均向用户展示可诊断错误，不静默吞掉
- [ ] 桌面端使用二级导航；窄屏可完成同等任务且不存在不可达操作
- [ ] 相关路由、状态和错误场景具有针对性测试

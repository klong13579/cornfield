# 04: 刷新模型目录并验证模型连通性

**What to build:** 用户可以刷新全部或单个 Provider 的运行时模型目录，看到数据来自哪里、何时更新、是否使用过期缓存以及刷新结果。用户还可以对单个模型发起最小真实调用，确认凭据、权限和模型响应是否正常，并获得耗时和可诊断错误。

**Blocked by:** 02: 交付可发现、可诊断的完整模型目录；03: 通过 Web 完成 Provider 接入

**Status:** ready-for-agent

- [ ] 支持全量刷新运行时模型目录
- [ ] 支持刷新单个 Provider，不影响其他 Provider 的有效缓存
- [ ] 每个 Provider 展示数据来源、上次刷新时间、缓存新鲜度、发现模型数和刷新错误
- [ ] 刷新失败时保留最后一次有效目录，并明确标记为过期数据而非伪装为最新
- [ ] 运行时刷新只更新权威缓存，不修改生成的静态模型目录文件
- [ ] 用户可对单个模型执行最小真实连通性测试
- [ ] 测试前明确提示会产生一次真实调用并可能产生费用
- [ ] 测试结果区分成功、认证失败、无模型权限、限流、网络错误和超时，并展示耗时
- [ ] 并发刷新、重复测试、断连和部分 Provider 失败具有针对性测试

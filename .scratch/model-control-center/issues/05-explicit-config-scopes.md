# 05: 显式管理全局和项目配置作用域

**What to build:** 用户编辑模型运行配置前，能够明确选择修改全局配置还是当前项目配置，并看到项目值与继承的全局值之间的关系。当前会话临时模型保持独立，不再与持久化默认模型混淆。恢复继承必须删除项目覆盖，而不是复制全局值。

**Blocked by:** 01: 建立模型控制中心信息架构

**Status:** ready-for-agent

- [ ] 运行配置工作区明确显示并切换全局与当前项目作用域
- [ ] 当前项目不存在项目级配置时，界面明确显示正在继承全局配置
- [ ] 每个可覆盖设置区分项目值、继承值和最终生效值
- [ ] “恢复继承”删除项目覆盖，不把当前全局值复制为项目值
- [ ] 当前会话临时模型、全局默认模型和项目默认模型在界面和协议中保持不同语义
- [ ] 保存响应说明实际写入的作用域和最终生效结果
- [ ] 项目配置缺失、损坏、只读或保存冲突时不产生部分写入
- [ ] 全局、项目覆盖、恢复继承和会话临时切换具有针对性测试

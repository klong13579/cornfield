# 06: 迁移到角色级模型路由

**What to build:** 每个内置或自定义角色拥有独立的主模型和有序回退链，运行时、CLI、TUI、Web 和 Gateway 对同一配置给出一致结果。旧的全局回退列表完成确定性迁移后被彻底删除，系统不保留两套可达表示。

**Blocked by:** 05: 显式管理全局和项目配置作用域

**Status:** ready-for-agent

- [ ] 内置角色和自定义角色统一表示为主模型加有序回退链
- [ ] 每个角色独立解析和执行自己的回退顺序，不再隐式共享全局回退列表
- [ ] 旧全局回退配置具有确定性、幂等的迁移规则，并覆盖空值、重复值和无效模型
- [ ] CLI、TUI、Web、Gateway 和运行时解析全部迁移到角色级表示
- [ ] 迁移期间按影响范围分批保持可验证，最终集成后只保留新表示
- [ ] 旧全局回退 schema、解析逻辑、写入路径、兼容分支和测试全部删除
- [ ] 配置读取失败或角色配置无效时返回真实错误，不静默采用看似合理的模型
- [ ] 每个受影响的模型选择和回退流程具有针对性测试
- [ ] 提交前通过变更影响检测确认旧表示没有剩余消费者

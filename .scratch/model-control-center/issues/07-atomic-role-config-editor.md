# 07: 交付原子化角色配置编辑器

**What to build:** 用户可以为内置和自定义角色配置主模型及有序回退链，在保存前检查完整差异。编辑过程保存在草稿中，只有整组配置校验和写入都成功后才生效，避免角色配置处于改了一半的中间状态。

**Blocked by:** 02: 交付可发现、可诊断的完整模型目录；06: 迁移到角色级模型路由

**Status:** ready-for-agent

- [ ] 角色列表展示主模型、回退数量、作用域和失效状态
- [ ] 用户可编辑内置角色并新增、复制、重命名和删除自定义角色
- [ ] 用户可搜索并选择主模型，添加、删除和调整回退模型顺序
- [ ] 编辑器检测重复模型、已停用模型、未接入 Provider、能力不匹配和不存在的模型
- [ ] 修改进入本地草稿，并提供放弃修改和恢复当前保存值
- [ ] 保存前展示作用域、逐项 diff 和潜在失效影响
- [ ] 保存操作原子执行；任一校验或写入失败时不得应用部分角色配置
- [ ] 保存成功后所有模型选择入口读取同一最终配置
- [ ] 草稿、diff、校验失败、原子保存和自定义角色生命周期具有针对性测试
